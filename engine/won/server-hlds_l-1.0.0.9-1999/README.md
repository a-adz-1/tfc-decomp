# hlds_l, WON 1.0.0.9 (dedicated server, 1999)

The 1999 Linux dedicated server: engine and launcher in one executable. QuakeWorld-style netcode (one update per client packet, no cl_updaterate, no lag compensation) and player movement in the engine.

- **Binary:** `hlds_l`
- **Release:** Linux HLDS 1.0.0.9, WON era
- **MD5 of the original:** `cc88b2d18bfc6997342ae199de00b8f6`
- **Contents:** Ghidra decompile, one file per name prefix or C++ class. Linux build with symbols.

The original binary is not included.
