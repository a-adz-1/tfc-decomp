# hw.so, pre-25th (client engine)

The client engine from before the 25th update (August 2020 build). Has text relocations, so data addresses show as ds:0x0 in plain objdump.

- **Binary:** `hw.so`
- **Version:** pre-25th Steam build
- **Built by Valve with:** GCC 4.x
- **MD5 of the original:** `6b09e190ae45062f567675153f2957e5`
- **Contents:** Ghidra decompile, one file per source file where the symbols allowed it (the binaries keep function symbols).

The original binary is not included.
