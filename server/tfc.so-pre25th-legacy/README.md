# tfc.so, pre-25th ("legacy") (server)

The TFC server game library from before the 25th Anniversary Update: Steam's `legacy` build and what most TFC servers run today. Push fields work as intended here.

- **Binary:** `tfc.so`
- **Version:** pre-25th-anniversary Steam build (the depot's `tfc.so`)
- **Built by Valve with:** GCC 4.6.1
- **MD5 of the original:** `6af84c23b4b43c0ba9b4061e426098a3`
- **Contents:** Ghidra decompile, one file per source file where the symbols allowed it (the binaries keep function symbols).

The original binary is not included.
