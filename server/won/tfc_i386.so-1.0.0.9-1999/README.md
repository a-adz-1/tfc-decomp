# tfc_i386.so, WON 1.0.0.9 (server, 1999)

The TFC server game library from the first Linux dedicated server (Half-Life 1.0.0.9, 1999). Player movement still lived in the engine then, so there is no pm_shared here; sentries already work as they do today.

- **Binary:** `tfc_i386.so`
- **Release:** Linux HLDS 1.0.0.9, WON era
- **MD5 of the original:** `8e24d17fd7ef325fc490b81a15229511`
- **Contents:** Ghidra decompile, one file per name prefix or C++ class. Linux build with symbols, so function and class names are real.

The original binary is not included.
