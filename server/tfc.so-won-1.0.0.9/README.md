The first TFC release's Linux server game library (Half-Life 1.0.0.9, late 1999). Player movement still lived in the engine in this version.

- **Version:** WON Half-Life 1.0.0.9 (hlds_l 1.0.0.9)
- **MD5 of the original:** `8e24d17fd7ef325fc490b81a15229511`
- **Contents:** Ghidra decompile, one file per name prefix or class; functions without a symbol are in `_unnamed*.c` (split at function boundaries to keep files small). Linux build with its global symbols kept (static functions are unnamed).
