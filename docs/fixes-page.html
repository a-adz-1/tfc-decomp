2OTFC Movement Fixes

Runs player movement with Valve's published Half-Life SDK movement code (with the legacy TFC server's behaviour), so bugs inside it can be fixed. With its fixes off it moves players exactly like the game: every frame of our movement tests is bit-for-bit identical to the original TFC.

Download 0.3 (Linux, with source) ↓

Fixes

FixSettingStatus
Ramp bug: at high fps the movement code could take a slope it hit twice for a corner and zero your speed. Now you keep slidingotfc_mf_rampfix 10.1
Ramp-save message: a chat line when the fix saves someone's slide, with their name and the speed they kept (one a second per player at most)otfc_mf_announce 1 (off by default)0.3
Instant unstick: free players stuck in walls or other players straight awayNext
Corners slide instead of stopping you dead (optional, off by default)Planned, vote

Tested

  • Same as the game with fixes off: all 3,030 frames of our movement scenarios (walking, crouching, falling, ladders, ramps, stairs, water, bunny hops, different frame rates) identical to the original.
  • Ramp fix on, real engine: the dead stops at 1000 fps are gone (e.g. 40° ramp at 600 u/s: 29 → 254 units up the ramp, in line with 500 fps), every other slide unchanged.
  • On the OTFC servers: loaded alongside TFC Fixes and AMX Mod X; tens of thousands of bot moves a minute run through it.

Install

  1. Copy addons/otfc_movefix/otfc_movefix_mm_i386.so from the zip to tfc/addons/otfc_movefix/.
  2. Add linux addons/otfc_movefix/otfc_movefix_mm_i386.so to tfc/addons/metamod/plugins.ini.
  3. Change map. Type otfc_mf in the server console: it shows the plugin on, how many moves it has run and how often the ramp fix stepped in.

Settings: otfc_mf_enable 0 hands movement back to the game; otfc_mf_rampfix 0 turns the ramp fix off; otfc_mf_announce 1 turns on the chat message when it saves a slide. Players' own games still predict the original movement, so when the fix steps in they may see one small correction at that moment.

Linux servers only for now. Source included: the plugin is MIT licensed; the movement code is from Valve's Half-Life SDK under its own licence (included), with every change marked.

3OTFC Sentry Options

One setting for how sentry guns pick targets. Mode 0 is the classic TFC sentry, untouched. Mode 1 targets the way Fortress United's sentry does.

Download 0.1 (Linux, with source) ↓
otfc_sg_modePicks a targetSees you if
0 (default)The first valid enemy by player slot, wherever they areA line from its eye to your eyes is clear
1The nearest valid enemyYour eyes or your body can be seen

Both modes keep the classic range (all round under 500 units, inside its view cone from 500 to 1000), turning speed, firing and damage. The mode can be changed any time and applies on the next server frame; otfc_sg in the server console shows the mode and how many targets mode 1 has picked.

Tested

  • On a local server with bot engineers and attackers: switched to mode 1 mid-game, sentries locked on with it, switched back to classic cleanly.
  • Mode 0 leaves the game's own sentry code exactly as it is.

Install

  1. Copy addons/otfc_sentry/otfc_sentry_mm_i386.so from the zip to tfc/addons/otfc_sentry/.
  2. Add linux addons/otfc_sentry/otfc_sentry_mm_i386.so to tfc/addons/metamod/plugins.ini.
  3. Change map, then set otfc_sg_mode 1 to try the improved targeting.

Linux, legacy tfc.so only (the 25th Anniversary build compiles the sentry's targeting into other code; the plugin then stays idle and says so). MIT licensed, source included.

4TFC Fixes

A metamod plugin by lazydaydreamer12 that fixes many bugs in TFC's game code, each switchable in its tfc_fixes.ini; tfx in the server console shows which fixes stepped in. Get it from its author:

TFC Fixes 1.2.0 on GitHub →

OTFC runs it with the default settings (push pads launch the same at any tick; the optional edge-conc fix is off). The investigation's metamod vs AMX Mod X page explains why these fixes are metamod plugins.
