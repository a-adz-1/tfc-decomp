Metamod or AMX Mod X?

Which kind of server plugin each proposed fix should be, and why.

1The two kinds of server plugin

Metamod

Compiled code (like TFC Fixes) that sits between the engine and the game. Fast, and the only kind that can replace the game's own steps, such as the movement code or a sentry's think. Harder to write and change.

AMX Mod X

Scripts that run inside the AMX Mod X plugin (itself a metamod plugin). Easy for the community to install, read and edit, but slower and limited to what AMX Mod X exposes. It can't change code inside the game's movement step.

3Why, fix by fix

Instant unstick

Before each move, check whether the player's box is inside something and, if so, move them to the nearest free spot. AMX Mod X can do this with the engine's own hull check. Metamod is still the better home: the check runs for every player on every move, so compiled code is cheapest, and it belongs with the other movement fixes.

Ramp bug

The cause is inside the movement code: a repeated surface is counted as a corner and your speed is zeroed. Only a metamod plugin can replace that step and fix it. AMX Mod X could only notice afterwards that a fast slide suddenly stopped, and give the speed back, which is guesswork and still loses that moment.

Corners

Same place in the movement code. From outside you can't tell a real corner stop from a harsh one, so there's no AMX Mod X workaround.

Sentry options

A metamod plugin can hook the sentry's think and change just the targeting or turning. AMX Mod X can't hook those steps on their own; it would have to take over the whole sentry and redo its turning, aiming and firing in script, reading the game's internal values from memory. Doable, but fragile and slow.

Ramp slides at any fps

Players' PCs predict their own movement with the original rules, so any server-side change to how slides work would correct players on every ramp. It needs a change on the client too, whatever kind of server plugin is used.

4Our plan

  • One metamod plugin next to TFC Fixes with instant unstick, the ramp-bug fix and (off by default) the corner fix, each switchable on its own.
  • Sentry options in metamod too, off by default, for the community to try and vote on.
  • Whatever the plugin, players' PCs still predict the original movement, so you'd see one small correction at the moments a fix kicks in.

Status: the ramp-bug fix is built and running on the OTFC servers (download); the rest is proposed. See Fixing movement for what each fix does.
