# client.dll, WON 3.1.0.1 (client, 2000)

The TFC client library from the HLDS 3.1.0.1 package (Half-Life 1.1 / TFC 1.5, 2000): the first TFC client library with client-side prediction and the netcode still used today.

- **Binary:** `client.dll`
- **Release:** from the HLDS 3.1.0.1 package (Windows DLL), WON era
- **MD5 of the original:** `162e3ece8c61dbe4e6c7fc1365086924`
- **Contents:** Ghidra decompile, one file per name prefix or C++ class. Windows build without symbols, so most functions are named by address.
