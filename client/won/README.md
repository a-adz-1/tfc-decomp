# WON-era clients (2000–2003)

Decompiles of the TFC client library (`client.dll`, Windows) from the WON-era packages. In 1999 (1.0.0.9) TFC
had no separate client library: that code was still in the engine. No symbols, so most functions are named by
address.

| Folder | Release |
|---|---|
| `client.dll-3.1.0.1-2000/` | 3.1.0.1 (2000, Half-Life 1.1 / TFC 1.5: first client-side prediction) |
| `client.dll-3.1.0.7-2002/` | 3.1.0.7 (2002) |
| `client.dll-3.1.1.1-2003/` | 3.1.1.1 (2003, last WON release) |

The WON client engines (`hw.dll`) are in `engine/won/`.
