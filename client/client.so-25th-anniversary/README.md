# client.so, 25th Anniversary (client)

The TFC client library shipped since the 25th Anniversary Update: what nearly every player runs. Its movement prediction is the same code as the server's `pm_shared`, compiled with the same compiler as the 25th `tfc.so`.

- **Binary:** `client.so`
- **Version:** 25th Anniversary update, current Steam default
- **Built by Valve with:** GCC 5.4.1, Steam Runtime scout
- **MD5 of the original:** `ee8b013336b49949cd3c4a335d0ef08f`
- **Contents:** Ghidra decompile, one file per source file where the symbols allowed it (the binaries keep function symbols).

The original binary is not included.
